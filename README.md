Lashes by Yordana

Уебсайт за услуги по миглопластика. Направен е с фокус върху изчистен дизайн, бързина и удобство при преглед от телефон.

🔗 **Сайт на живо:** [lashesbyyordana.com](https://lashesbyyordana.com)

Какво съдържа проектът
- Изцяло адаптивен (responsive) дизайн за мобилни устройства и компютри
- Интеграция с Netlify за автоматичен деплой при промени в GitHub
- Настроен собствен домейн и DNS управление (`lashesbyyordana.com`)

Технологии
- HTML5 & CSS3
- Git & GitHub
- Netlify
